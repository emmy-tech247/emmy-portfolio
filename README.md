# Emmanuel Alao Portfolio (Next.js + React + Tailwind)

## Run locally
    npm install
    npm run dev        # http://localhost:3000

## Add your images to /public
- emmanuel.png (hero photo)
- sarah.jpg, client2.jpg, client3.jpg (testimonial photos)
- projects/real-estate.jpg, projects/fintech.jpg, projects/ecommerce.jpg
- Emmanuel-Alao-CV.pdf

## Deploy to Azure Static Web Apps
    npm run build      # outputs ./out
App location: /   |   Output location: out   |   Build command: npm run build
